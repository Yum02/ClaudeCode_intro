# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project overview

This repository is a personal learning log for practicing "vibe coding" with Claude Code — there is no application code, build system, or test suite. The only content is `README.md`, which documents the project's purpose and the logging convention below.

## Logging convention

New learning sessions are recorded as dated entries appended to the "학습 로그" (Learning Log) section of `README.md`, using this template:

```
### YYYY-MM-DD - 주제
- 시도한 것:
- 배운 점 / 느낀 점:
- 다음에 해볼 것:
```

When the user reports what they tried or learned in a session, add a new entry following this template rather than rewriting existing entries. Keep entries in chronological order and do not delete past entries.
